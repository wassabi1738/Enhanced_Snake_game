# Enhanced_Snake_game
A complete, polished Snake game with scoring, start/end screens, difficulty selection, sound effects, and beautiful visuals — all in one HTML file

How it works:
🥇 Scoring- Score updates live in the HUD. High score is saved in localStorage so it persists even after you close the browser.
🎬 Start Screen- A polished menu with title, subtitle, and difficulty buttons. Click Start Game to play.
💀 Game Over Screen-	Shows your final score, high score, and buttons to Play Again or go back to Menu.
🎯 Difficulty Selection-	Choose Easy, Medium, Hard, or 🔥 Insane — this changes the tick speed (interval in ms).
🔊 Sound Effects-	Three distinct sounds generated via the Web Audio API (no external files needed):<br>• 🍎 Eat — happy ascending tones<br>• 💥 Die — descending crash<br>• 🚀 Start — cheerful arpeggio

🎨 Visual Effects:	
• Radial gradient background
• Pulsing apple with glow, stem & leaf
• Rounded snake segments with gradient colours (bright green head → darker tail)
• Cute eyes on the snake's head that point in the movement direction
• Subtle grid overlay
• Glass-morphism UI panels with backdrop blur

🎮 Controls:
Key	Action
⬆️ / W	Move up
⬇️ / S	Move down
⬅️ / A	Move left
➡️ / D	Move right
